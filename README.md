# House Price Prediction

IBM SkillsBuild Data Analytics with AI Internship 2026 - course project.

Predict the sale price of a house (`SalePrice`) from 79 property features using
the Kaggle **House Prices - Advanced Regression Techniques** dataset (Ames, Iowa).

Prediction task: **supervised regression**, scored (on Kaggle) with
**Root Mean Squared Logarithmic Error (RMSLE)**.

---

## Dataset

- **Source (dataset resource):** Kaggle competition *House Prices - Advanced Regression Techniques*, Data tab:
  <https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data>
- **Competition page:** <https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques>
- **Download:** the raw CSV files are **not included in this repository**.
  Kaggle's competition rules allow the data for *Competition Use and Academic,
  Non-Commercial Use only* and prohibit republishing it to anyone not
  participating in the competition, so the raw files stay out of Git. To run the
  notebook you must download them yourself:
  1. Create an account (or sign in) on Kaggle.
  2. Open the dataset resource link above (Data tab), or navigate from the
     competition page to the **Data** tab.
  3. Click **Download All**, unzip it, and place the four files in a local
     `data/` folder in this project:

     ```
     data/train.csv
     data/test.csv
     data/sample_submission.csv
     data/data_description.txt
     ```

  The notebook uses relative paths (`data/...`) and never modifies these files.
- **Files** (in `data/`, kept unchanged):
  - `train.csv` - 1,460 rows x 81 columns (80 features + `SalePrice`)
  - `test.csv` - 1,459 rows x 80 columns (features only)
  - `sample_submission.csv` - 1,459 rows x 2 columns (template `Id`, `SalePrice`)
  - `data_description.txt` - plain-text dictionary of all features

## Setup and run

Requires Python 3.14+ (tested with 3.14.6).

```bash
# 1. install dependencies
pip install -r requirements.txt

# 2. run the notebook (execute all cells from a clean kernel)
jupyter notebook Rittik_HousePricePrediction.ipynb
# or without a browser:
python -m nbconvert --to notebook --execute --inplace \
       --ExecutePreprocessor.timeout=900 Rittik_HousePricePrediction.ipynb
```

The notebook loads `data/` with relative paths, so run it from this folder.
Running it end-to-end produces `submission.csv` (1,459 predictions).

### Train the model from the command line (optional)

The same Lasso pipeline, without the notebook:

```bash
python train_model.py
```

Reads `data/train.csv` + `data/test.csv`, applies the identical preprocessing,
fits Lasso (alpha=0.0005), writes `submission.csv`, and saves the trained
pipeline to `model/house_price_pipeline.joblib`.

### Open the website (localhost)

```bash
python app.py
```

Then open **http://127.0.0.1:5000** in your browser: a form lets you set the
main house features and returns an estimated sale price from the trained model.
It needs `model/house_price_pipeline.joblib` (run `train_model.py` first if it
is missing). Fields not shown in the form use the training-set median/most
common value.

**View the project report as a web page** (same content as
`Rittik_ProjectReport.docx`, including all diagrams):
**http://127.0.0.1:5000/report**

* `app.py` serves two pages: prediction form (`/`) and the report (`/report`).
* Figures are served from the `figures/` folder (11 PNG diagrams extracted
  from the notebook).

## What the notebook does

1. **EDA** - shapes/dtypes/duplicates, `SalePrice` distribution (raw vs `log1p`),
   missing-value analysis (many `NaN` mean "feature absent", not lost data),
   correlations and key feature plots.
2. **Preprocessing** - absent-feature `NaN` -> `None`, ordinal quality codes,
   fixed outlier rule (`GrLivArea > 4000`, 4 rows removed, audited), one sklearn
   `Pipeline` (median imputation + scaling; most-frequent imputation + one-hot),
   refitted **inside every CV fold** (no data leakage). 261 features.
3. **Models** - `DummyRegressor`, `Ridge`, `Lasso`, `Random Forest`, `XGBoost`,
   all scored with 5-fold CV (seed 42) and the same RMSLE definition.
4. **Tuning** - `GridSearchCV` on the same folds; only validation folds used.
5. **Held-out validation** - fresh 80/20 split (seed 42), tuned on 80% only,
   scored once on 20%.
6. **Submission** - final Lasso refit on all labeled rows, `test.csv` predictions,
   `expm1` back-transform, non-negative safeguard, verified `submission.csv`.

## Verified results (from the executed notebook)

Stage 4A - model comparison (5-fold CV RMSLE, seed 42):

| Model | CV RMSLE mean +/- std |
|---|---|
| Ridge (alpha=10) | 0.11508 +/- 0.00756 |
| XGBoost | 0.12343 +/- 0.01186 |
| Lasso (alpha=0.005) | 0.12495 +/- 0.01137 |
| Random Forest | 0.13778 +/- 0.01349 |
| Dummy baseline | 0.39604 +/- 0.01831 |

Stage 4B - tuned (best CV RMSLE on the same folds):

| Model | Best params | CV RMSLE |
|---|---|---|
| Lasso | alpha=0.0005 | 0.11396 |
| Ridge | alpha=25 | 0.11504 |
| XGBoost | lr=0.05, depth=3, n=600 | 0.11744 |

Stage 5 - honest held-out validation (80/20, seed 42; tuned on 80% only):

| Model | train-CV RMSLE | held-out val RMSLE |
|---|---|---|
| Lasso (alpha=0.0005) | 0.11213 | **0.12026** |
| Ridge (alpha=25) | 0.11387 | 0.12284 |
| Dummy baseline | 0.39483 | 0.39872 |

**Selected model:** Lasso, `alpha=0.0005`.

Stage 6 - `submission.csv`: 1,459 rows, `Id`, `SalePrice`; ID order matches
`sample_submission.csv`; all predictions non-negative and finite.

> **Honesty note:** no `test.csv` labels exist, so no Kaggle score is claimed.
> The real test-set error can only be measured after an actual Kaggle
> submission. The held-out validation RMSLE is a single-split estimate.
