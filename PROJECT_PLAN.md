# House Price Prediction — Project Plan

Project for the **IBM SkillsBuild Data Analytics with AI Internship 2026**.
Dataset: **Kaggle House Prices — Advanced Regression Techniques** (Ames, Iowa).

## 1. The Prediction Task

**Supervised regression.** Predict the sale price of a house (`SalePrice`)
from 79 property features (size, quality ratings, condition, neighbourhood,
basement/garage details, sale year, etc.).

Evaluation metric on Kaggle: **Root Mean Squared Logarithmic Error (RMSLE)**.

## 2. Verified Dataset Summary

| File | Rows | Columns | Notes |
|------|------|---------|-------|
| `data/train.csv` | 1460 | 81 | 80 features + target `SalePrice` |
| `data/test.csv` | 1459 | 80 | features only (no `SalePrice`) |
| `data/sample_submission.csv` | 1459 | 2 | format: `Id`, `SalePrice` |
| `data/data_description.txt` | — | 79 features | explains every feature + categories |

Key facts observed during the initial check:

- `SalePrice` is an integer, range $34,900 – $755,000, mean ≈ $180,921.
- Mixed data types: ~43 text/categorical, ~38 numeric.
- **19 columns** in `train.csv` have missing values. The most affected:
  - `PoolQC` (99.5%), `MiscFeature` (96.3%), `Alley` (93.8%), `Fence` (80.8%),
    `MasVnrType` (59.7%), `FireplaceQu` (47.3%), `LotFrontage` (17.7%).
  - Note: `NA` in many of these means *"feature does not exist"*
    (e.g. no pool, no fence) — so "missing" is often meaningful, not random.

## 3. Project Stages

1. **Setup (done)**
   - Verify raw dataset files (unchanged, preserved in `data/`).
   - Create `PROJECT_PLAN.md`, `.gitignore`.
2. **EDA (Exploratory Data Analysis)** — in the notebook
   - Target distribution + skewness; log-transform `SalePrice`
     (needed for RMSLE).
   - Missing-values analysis (distinguish missing vs `NA` = absent feature).
   - Correlations with `SalePrice` (e.g. `OverallQual`, `GrLivArea`,
     `GarageCars`, `TotalBsmtSF`).
   - Feature engineering (TotalSF, age, basement/garage indicator, etc.).
3. **Data Preprocessing**
   - Handle missing values (impute / create "None" categories).
   - Encode categorical features (one-hot / ordinal).
   - Outlier handling.
4. **Modeling**
   - Train/validation split on `train.csv` (model must NOT see `test.csv`).
   - Models to try: Linear Regression, Ridge/Lasso, Random Forest,
     Gradient Boosting / XGBoost, and a simple baseline for comparison.
   - Tune hyperparameters; compare by validation RMSLE.
5. **Evaluation**
   - Log-transform the target; compute RMSLE on validation set.
   - Choose best model; check for overfitting.
6. **Submission**
   - Predict on `test.csv`, format per `sample_submission.csv`.
   - Bonus (if time allows): upload to Kaggle for a public score.
